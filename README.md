# Project B - Utilities Library

Библиотека утилит для работы с датами и строками.

## Возможности

### Работа с датами

- получение текущей даты;
- форматирование даты;
- вычисление количества дней между датами;
- добавление дней к дате.

### Работа со строками

- разворот строки;
- проверка на палиндром;
- подсчёт слов;
- преобразование первой буквы каждого слова в заглавную.
